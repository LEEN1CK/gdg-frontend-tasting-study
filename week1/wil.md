# WEB 구성
  ### 1. HTML
      : HyperText Markup Language
      웹페이지의 뼈대와 구조를 적는 언어
      제목, 글, 이미지, 버튼, 입력창, 링크 등의 위치와 역할 정의

  ### 2. CSS
      : Cascading Style Sheets
      웹페이지의 시각적 모습을 입히는 언어
      색상, 폰트, 크키, 간격, 위치 등을 지정

  ### 3. JS
      : JavaScript
      웹페이지의 상호작용과 동적 기능을 담당하는 언어
      클릭, 스크롤, 키보드 입력 등 사용자 이벤트 감지 및 실행
