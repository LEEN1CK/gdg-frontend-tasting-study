# 배운 것
  ### React
    : JavaScript에 있는 라이브러리로 UI를 만들 때 필요한 코드를 해당 라이브러리에서 가져와서 사용한다.

  ### JSX
    : JavaScaript 안에서 UI를 표현하기 위한 문법으로, HTML과 비슷하며, 이를 통해 화면을 설계하고 구현한다.

  ### 화면 설계하기
    1. 화면을 Profile, Image, Action, Content 등 네 개의 영역으로 구조를 찾는다.
    2. 각 영역에서 사용자의 상호작용에 따르는 동작을 생각한다. 
    3. React에서 각각의 영역을 구현하고, 동작을 코드로 표현한다.
